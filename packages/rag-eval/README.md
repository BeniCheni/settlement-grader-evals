**The verdict is ship (the owner's, ruling 51).** Variant B, alias matching for rule lookups, meets all three bars set before either run. Recall rose by 0.014 with a 95% interval of [0.003, 0.029]. Faithfulness fell by 0.016, [-0.031, -0.003], inside its bar of -0.05. Both variants matched 80 of 159 outcomes. The full table is in `assignment-2/report.md`.

**In sample, or held out.** The alias table was written knowing the six lookup misses on record, so B's effect on those six is in sample. v1's 29 real rows are tickets the grader graded in earlier runs, where those misses were seen. Each variant made one pass on one machine, so the intervals cover the rows and not a second pass. Only 5 of v1's 159 keys are `verified_by_beni`. `pilot` reads the committed candidates and the two pilot runs, and `freeze` reads the kept list. Neither needs a model, and these commands rebuild all five committed files at a scratch path and compare them:

```bash
mkdir -p .t
python3 -m scorer.golden pilot --kept .t/kept.jsonl --pilot-md .t/pilot.md
python3 -m scorer.golden freeze --kept data/golden/kept.jsonl --v1 .t/v1.jsonl --sha .t/v1.sha256 --copy .t/golden_set.jsonl
cmp .t/kept.jsonl data/golden/kept.jsonl && cmp .t/pilot.md packages/rag-eval/assignment-1/pilot.md
cmp .t/v1.jsonl data/golden/v1.jsonl && cmp .t/v1.sha256 data/golden/v1.sha256 && cmp .t/golden_set.jsonl packages/rag-eval/assignment-1/golden_set.jsonl
shasum -a 256 -c data/golden/v1.sha256
```
