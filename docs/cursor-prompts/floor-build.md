WHY THIS PR EXISTS. Three A/A runs of the v1 configuration gave the same final answer on all 32 tickets, and 21 of 32 differ from traces/v1, with the same recorded configuration. Nothing in a run records the Ollama server version or the model's digest, so nothing can say what changed. The owner ruled on Thu 29 Oct 2026 (decision 5 in the plan) that a run records both and that a difference between setups is reported as a change of environment. This PR makes the grader's run record them and adds one command that compares two runs. It runs no grader, edits no committed run and calls no model in its tests.

HAZARDS THE PM SEAT KNOWS ABOUT, to check and not to trust. Do not change score_run's own output to fix it. (b) run_eval.py creates traces/<run_id>/ before it grades the first ticket; the spec says a run whose version or digest cannot be read stops before it writes a file, so the check must come before that directory is made, and a test proves no directory is left behind. (c) On main, scoring each committed run gives these code counts, in CHECKS order, as the PM read them at 0aa5280: traces/v1 14, 14, 9, 5, 5, 6, 3, 3, 3, 2, 2; each of traces/aa-1, traces/aa-2 and traces/aa-3 15, 15, 8, 5, 5, 7, 2, 1, 5, 0, 2.
