GAPS IN THE SPEC THIS PROMPT RESOLVES, each named in the PR body under "Resolution". (1) ab takes an optional --cases FILE, default data/gold.json, as scorer.compare does, so fixtures can use their own; run-ab reads no cases file. (2) The page never prints the path it was written to. Its colophon prints the command with its inputs as given, followed by a fixed --html reports/ab.html and no --md or --json, so a report written elsewhere has the same bytes, as the judge page does with comparison.html. A test runs that printed command from a scratch copy of the repository and compares what it writes with the page. (3) False passes read: print "k of n" when set 1's side has false passes, and the words "no false passes" when it has none. Never print "0 of 0", which reports/judge-set1.json holds and the judge page already refuses to print. (4) paired_difference returns a tuple (fall, lower, upper), and None when n is 0. (5) Number formats. A share or a delta in percentage points is computed from the integer counts, not by formatting a float, to one decimal, with an explicit sign on a delta and an exact half rounding away from zero in both directions, so the bytes match on 3.9 and 3.14. agreement_percent handles only non-negative values; do not change its behaviour. Interval limits are given in points to one decimal from the float, and "-0.0" prints as "0.0". (6) must_fall holds when (A's count minus B's count) is at least min_net_fall and, if interval_excludes_zero, the interval's lower limit is strictly above zero. If A's count is below min_net_fall the row fails; it is not a refusal. max_rise holds when (B's count minus A's) is at most max_rise. max_pass_fall holds when (A's PASS count minus B's) is at most max_pass_fall. (7) thresholds.json's top-level keys are exactly code, interval, judge and weakest_judge; interval.method must be newcombe-1998-method-10, and interval.z is what the report passes to paired_difference. Anything else is a refusal. (8) The thresholds' count is plain ink, whatever it says. A slime tile or pill reading "8 of 8" is a trust verdict in everything but name. A failed row may be blood; a row that held is ink.
